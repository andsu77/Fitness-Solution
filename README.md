# Fitness Solution

Site MVC em Node.js + Express + EJS.

## Rodar localmente

1. Instale Node.js.
2. Abra o terminal nesta pasta.
3. Execute:
   npm install
4. Copie `.env.example` para `.env`.
5. Execute:
   npm run dev
6. Abra http://localhost:3000

## Publicação

O projeto precisa ser colocado em uma hospedagem que rode Node.js (por exemplo, Render, Railway ou outro serviço compatível). Depois, conecte um domínio e configure as variáveis de ambiente.

## AdSense

Não há código de anúncios neste pacote. Primeiro publique o site, revise conteúdo/políticas, configure Search Console e então cadastre o domínio no Google AdSense. O código do AdSense deve ser inserido conforme as instruções fornecidas pelo Google após a aprovação/configuração.

## Antes de monetizar

- Trocar `SEU-DOMINIO.com` em robots.txt e sitemap.xml.
- Completar Política de Privacidade e Cookies de acordo com as ferramentas realmente usadas.
- Adicionar conteúdo original e útil.
- Revisar as informações de saúde/fitness com fontes confiáveis.
- Criar uma página de contato real.
- Não publicar recomendações individualizadas como se fossem prescrição profissional.
